# Lib

## Cell-tile rendering and highlight filters on Rows/Show
Rows/Show.vue (one row's cell×flat grid) renders individual cells via CellSlot.vue and its highlight-filter state/logic via CellHighlightFilters.vue + lib/cellHighlight.ts (matchesCellHighlight, emptyCellHighlightFilters). The date/state predicates themselves (isCellExpiringWithin, isCellExpired, isCellStale) live in lib/cellStatus.ts, whose only importer is cellHighlight.ts — the pages and components reach them exclusively through `matchesCellHighlight`, so add a new predicate there rather than importing cellStatus.ts directly into a component. The actual highlight matching (state/expired/expires-within-days/product/stale-after-days) is purely client-side — the whole page's cells are already loaded in one request — never wire the *matching computation* itself into a router.get (the matching pallets list, `PalletController::index`, applies the same params server-side through `Pallet::matchingHighlightFilters()`, which must stay in lockstep with these predicates). CellHighlightFilters.vue's model is a reactive() object mutated in place (v-model on nested fields, Object.assign in clear()); it never emits update:modelValue, so pass it with :model-value="..." not v-model, and the parent must own a reactive(), not a plain ref. There is no automatic/filterless expiry emphasis anywhere — CellSlot has no expiry border, badge, or colored expiration text of its own; the only emphasis a cell ever gets is the highlight ring (ring-blue-500) when it matches an *explicitly applied* highlight filter. `isCellExpiringWithin` excludes already-past-due pallets (today-through-N-days-out only); `isCellExpired` is the separate helper/filter for "already overdue" — see components-js-lib.md. This was a deliberate removal of a prior "expiring soon window" (ExpiringDaysInput/expiringDays/expiringSoonUntil) feature that duplicated the expires-within-days highlight filter and auto-emphasized expired/soon cells without the user choosing to; don't reintroduce a parallel expiry-window mechanism outside the highlight filters. CellSlot also has no staleness badge — a stale match is communicated only by the same highlight ring, not a separate icon, so a pallet that's both expiring and stale doesn't get overlapping badges.
